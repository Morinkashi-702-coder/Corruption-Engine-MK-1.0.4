6. BUILDING THE ENGINE
------------------------------------------------------------
Open a terminal in the source root: the folder containing
Project.xml, source/ and assets/.

Build the Windows release:
haxelib run lime build windows

This compiles without opening the game.

Build and launch it:
haxelib run lime test windows

If the Lime command alias is configured, these also work:
lime build windows
lime test windows

Both forms run Lime. If "lime" is not recognized, use
"haxelib run lime" to run it through Haxelib without relying
on the Lime command alias. This does not replace installing
the required tools and libraries.

The first build can put a heavy load on the CPU and use
substantial RAM. Compiling on a low-end PC is not recommended
if you need the computer to remain responsive: it may take
a long time and other programs may slow down. It can still
be possible; a slow first build alone does not mean an error.
Later builds usually reuse compiled files and take less time
when only a few files have changed. To play, use the ready-made
release; you do not need to compile the source.

Expected release executable:
export\release\windows\bin\PsychEngine.exe

Close running copies of the game before rebuilding.
Otherwise Windows may lock PsychEngine.exe or lime.ndll.

WARNING: Back up your mods and personal files in export.
Do not run "lime clean windows" on a working installation
that contains your only copy of a mod or recreation.
Normal build/test is the intended workflow for this project.
